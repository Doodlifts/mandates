Every AI agent wants your wallet.
There are only bad ways to hand it over.

Agents are getting good enough to manage money. The missing piece isn't intelligence — it's a safe way to delegate.

OPTION 1 — GIVE IT KEYS

Full custody

One bug, one prompt injection, one malicious skill update — and everything is gone. You're trusting every line of software between the model and the chain.

OPTION 2 — TOKEN APPROVAL

All-or-nothing

ERC-20 approve has no budget, no schedule, no direction, no expiry. An approved spender can drain the allowance in one block, in one direction: away.

OPTION 3 — WALLET POLICIES

Rules in the actor

Session keys and policy engines put enforcement in wallet software — the layer the agent operates. Better, but the rules live next to the thing they're restraining.

Mandates move the rules to the venue. The Uniswap v4 pool re-validates every trade inside its own execution path. A compromised agent, a rogue operator, a hallucinating model — none of it matters, because the pool rejects anything outside the envelope.

  • exceed the per-epoch budget
  • trade the forbidden direction
  • touch any other pool
  • keep trading after you revoke
  • outlive its expiry
  • withdraw your funds — ever
  • route around the rules via another router
  • lose your custody: you can always pull out

Each rejection above is a named on-chain error with a test proving it: BudgetExceeded · DirectionForbidden · Revoked · Expired · WrongPool · NotMandateBook

How it works

Three steps. Custody never moves.

STEP 1

Deposit

Fund your vault. Only you can ever withdraw — no mandate, executor, or admin path touches it.

STEP 2

Write the policy

Pool, per-epoch budget, direction, expiry. The policy is on-chain data — readable, auditable, boring.

STEP 3

Hand over the capability

The mandate is an ERC-6909 token. Whoever holds it can act — inside the envelope. Transfer it to delegate; revoke to kill it. Revocation always wins.

Guards: pre/post conditions for pools

An oracle price band checked before and after every swap. A trade whose impact would push the pool off-market unwinds entirely — built-in manipulation and fat-finger protection, for mandated and ordinary flow alike.

Chrono: swap traffic as a clock

Scheduled jobs (DCA legs, rebalances) ride other people's swaps and pay them a bounty for the gas. No keeper subscription; a permissionless poke keeps liveness when markets are quiet.

For builders: agents hold mandates today

An MCP server makes any Claude (or MCP-capable) agent a mandate executor. The agent is assumed hostile — the envelope holds anyway.

# wire the mandates MCP server into Claude Code
claude mcp add mandates \
  -e MANDATE_RPC_URL=https://... \
  -e MANDATE_BOOK=0xYourMandateBook \
  -e MANDATE_PRIVATE_KEY=0xExecutorKey \  # executor key, NOT your keys
  -- npx tsx mcp/src/index.ts

# the agent sees four tools:
mandate_status   → live policy + remaining budget
mandate_execute  → one swap inside the envelope (simulated first)
executor_info    → who am I, gas balance
vault_balance    → owner's funds available

# and a boundary it can reason about:
"BudgetExceeded means you hit your allowance —
 a hard boundary, not an error to retry."
